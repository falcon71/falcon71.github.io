<Field id="ident" title="Identifier of the user airport">
	The identifier of a <Term t="User waypoint">user airport</Term>, up to four characters. The identifier is the one you entered when you created the airport.
</Field>

<Field id="pos" title="Position of the user airport">
	The position of the user airport, latitude above and longitude below. With the cursor on, the cursor can stop on each of them, and a new value changes the stored position when you press <kbd>ENT</kbd>. The airport has no name, and no airspace is shown for it.
</Field>

<Field id="page" title="Page name">
	The name of the page on the right side.
</Field>
