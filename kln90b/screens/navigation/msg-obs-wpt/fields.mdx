<Field id="message" title="OBS waypoint far away">
	`OBS WPT > 200NM`: in OBS mode, the active waypoint is more than 200 NM away. See [`OBS WPT > 200NM`](/kln90b/operation/modes-of-operation/#obs-wpt--200nm).
</Field>

<Field id="mode" title="Mode annunciation">
	<Term t="ENR:">`ENR:`</Term> and a three-digit course: Enroute-OBS mode, with the selected course as a magnetic course. See [The mode annunciations](/kln90b/operation/modes-of-operation/#the-mode-annunciations).
</Field>

<Field id="msg" title="Message prompt">
	<Term t="MSG">`MSG`</Term> steady in inverse video: you have read every message the unit holds; it flashes while one is unread. <kbd>MSG</kbd> shows the next one or closes the page after the last ([The message prompt](/kln90b/operation/messages/#the-message-prompt)).
</Field>
