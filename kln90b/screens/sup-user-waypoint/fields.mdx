<Field id="ident" title="Identifier of the user waypoint">
	The identifier of the [user waypoint](/kln90b/operation/user-waypoints/). It cannot be changed after the waypoint is created.
</Field>

<Field id="ref" title="Reference waypoint">
	The waypoint that `RAD` and `DIS` are measured from. For a waypoint that was not made from a reference, the unit looks for the nearest VOR about 8 seconds after the page appears, and the field stays empty until it has found one. You can enter any waypoint instead: the unit shows it on its waypoint page for approval, and the page then shows radial and distance from it.
</Field>

<Field id="rad" title="Radial from the reference waypoint">
	The magnetic course from the reference waypoint to the user waypoint, in degrees and tenths. A new radial moves the user waypoint along the new radial at the same distance from the reference waypoint. As long as there is no reference waypoint, a radial you enter is shown but moves nothing.
</Field>

<Field id="dis" title="Distance from the reference waypoint">
	The distance from the reference waypoint to the user waypoint in NM, to a tenth. A new distance moves the user waypoint along the same radial. As long as there is no reference waypoint, a distance you enter is shown but moves nothing.
</Field>

<Field id="lat" title="Latitude of the user waypoint">
	The latitude of the user waypoint, in degrees and minutes to hundredths. With the cursor on, a new latitude moves the waypoint when you press <kbd>ENT</kbd>, and the stored waypoint changes at once.
</Field>

<Field id="lon" title="Longitude of the user waypoint">
	The longitude of the user waypoint, in degrees and minutes to hundredths. With the cursor on, a new longitude moves the waypoint when you press <kbd>ENT</kbd>, and the stored waypoint changes at once.
</Field>

<Field id="page" title="Page identification">
	The page identification on the right side.
</Field>
