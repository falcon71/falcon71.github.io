<Field id="message" title="Check the baro setting">
	The unit has changed to an approach arm mode and asks you to check the altimeter baro setting. Press <kbd>ALT</kbd>, check the setting on the ALT page ([The baro setting](/kln90b/operation/alerts/#the-baro-setting)), and press <kbd>ALT</kbd> again; the message goes once the ALT page has been shown. See [`PRESS ALT TO SET BARO`](/kln90b/operation/approaches/#press-alt-to-set-baro).
</Field>

<Field id="mode" title="Mode annunciation">
	<Term t="ARM-LEG">`ARM-LEG`</Term>: Approach Arm-Leg mode, the approach is armed. See [Arming the approach](/kln90b/operation/approaches/#arming-the-approach).
</Field>

<Field id="msg" title="Message prompt">
	<Term t="MSG">`MSG`</Term> steady in inverse video: you have read every message the unit holds; it flashes while one is unread. <kbd>MSG</kbd> shows the next one or closes the page after the last ([The message prompt](/kln90b/operation/messages/#the-message-prompt)).
</Field>
