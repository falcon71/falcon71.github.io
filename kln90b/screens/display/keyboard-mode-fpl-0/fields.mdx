<Field id="waypoints" title="Waypoints of the flight plan">
	The waypoints entered so far, each with its number in the flight plan. The [active leg symbol](/kln90b/pages/fpl/#the-active-leg-symbol) in front of the first two waypoints shows the active leg.
</Field>

<Field id="next" title="Blank waypoint position">
	The blank waypoint position after the last waypoint, with the cursor on it. After <kbd>Enter</kbd> approves a waypoint, the cursor stands here, ready for the next identifier.
</Field>

<Field id="kybd" title="Keyboard mode annunciation">
	`KYBD` flashes in place of the `CRSR` annunciation while keyboard mode is on for the left side. When keyboard mode ends with the cursor still on, `CRSR` returns.
</Field>
