<Field id="waypoints" title="Waypoints of the flight plan">
	The waypoints entered so far, each with its number in the flight plan. The marks in front of the first two waypoints show the active leg.
</Field>

<Field id="next" title="Next waypoint">
	The blank entry at the end of the flight plan, with the cursor on it. After <kbd>Enter</kbd> approves a waypoint, the cursor stands here, ready for the next identifier.
</Field>

<Field id="kybd" title="Keyboard indication">
	`KYBD` flashes in place of the `CRSR` annunciation while keyboard mode is on for the left side. When it ends, `CRSR` returns; the cursor stays on.
</Field>
