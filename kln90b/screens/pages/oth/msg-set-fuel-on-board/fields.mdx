<Field id="message" title="Set fuel on board">
	`SET FUEL ON BOARD` `ON OTH 5 IF NECESSARY` asks you to enter the fuel on board on OTH 5, because the aircraft does not send it. The message is gone once you have read it.
</Field>

<Field id="mode" title="Mode annunciation">
	The mode annunciation; <Term t="ENR-LEG">`ENR-LEG`</Term> is Enroute-Leg mode. It stays in the status line while the MSG page is shown.
</Field>

<Field id="msg" title="Message prompt">
	<Term t="MSG">`MSG`</Term> steady: you have read every message the unit holds; it flashes while one is unread. Pressing <kbd>MSG</kbd> shows the next page of messages or closes the MSG page. See [the message prompt](/kln90b/operation/messages/#the-message-prompt).
</Field>
