<Field id="title" title="Page title">
	`USER WPTS` heads OTH 3, the list of all [user waypoints](/kln90b/operation/user-waypoints/). The list has one row per waypoint and scrolls with the cursor.
</Field>

<Field id="idents" title="Identifiers">
	The identifier of each user waypoint. The list starts with the user-defined airports, then the VORs, the NDBs, the intersections and the supplemental waypoints, and sorts by identifier within each of these. Waypoints that the unit made for itself are in the list too.
</Field>

<Field id="types" title="Waypoint types">
	The waypoint type of each row: `A` for a user-defined airport, `V` for a VOR, `N` for an NDB, `I` for an intersection and `S` for a supplemental waypoint.
</Field>

<Field id="plan" title="Flight plan that holds the waypoint">
	The number of the lowest-numbered flight plan that contains the waypoint, `0` for FPL 0. The field is blank for a waypoint that no flight plan holds.
</Field>

<Field id="page" title="Page identification">
	The page identification of the left page, `OTH 3`.
</Field>
