<Field id="title" title="Page title">
	`HT ABOVE APT ALERT` heads the page of the height above airport alert.
</Field>

<Field id="enable" title="Height above airport alert">
	`OFF` or `ON`. With the alert on, the page adds the offset height below it; with it off, the offset height is hidden and the cursor skips it. With the cursor on, the left inner knob changes the setting at once, without <kbd>ENT</kbd>.
</Field>

<Field id="offset" title="Offset height">
	`APT ELEV` and the offset height: the height above the elevation of the airport, in ft, at or below which the alert sounds. It runs from 800 ft to 2,000 ft in steps of 100 ft, and the left inner knob steps around the values with the cursor on it. The change takes effect at once.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> takes the place of the page identification of the left side while that side's cursor is on.
</Field>
