<Field id="title" title="Page title">
	`AIRSPACE ALERT` heads the page of the airspace alert.
</Field>

<Field id="enable" title="Airspace alert">
	`DISABLE` means that the airspace alert is off. The vertical buffer is hidden, and the cursor cannot go to it. `ENABLE` turns the alert on and shows the buffer again. With the cursor on, the left inner knob changes the setting at once, without <kbd>ENT</kbd>.
</Field>

<Field id="page" title="Page identification">
	The page identification of the left page, `SET 8`.
</Field>
