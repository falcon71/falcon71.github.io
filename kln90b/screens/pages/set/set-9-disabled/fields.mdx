<Field id="title" title="Page title">
	`ALTITUDE ALERT VOLUME` heads the page that sets the volume of the aural alarm.
</Field>

<Field id="off" title="Volume off">
	`OFF` is the only state the page shows in an installation without altitude alerting. You cannot change it, because the cursor cannot go to the page.
</Field>

<Field id="disabled" title="Feature disabled">
	`FEATURE DISABLED` says that the installation of the unit has no altitude alerting, and so no aural alarm to set the volume of.
</Field>

<Field id="page" title="Page identification">
	The page identification of the left page, `SET 9`.
</Field>
