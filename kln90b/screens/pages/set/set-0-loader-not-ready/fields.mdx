<Field id="title" title="Page title">
	`U P D A T E` `D A T A   B A S E`, the title of the page, in letters spread apart. It is a full-screen page, which takes both halves of the screen.
</Field>

<Field id="loader" title="Loader not ready">
	The message `L O A D E R` `N O T   R E A D Y` ends the update and turns the cursor off. The simulation has no loader behind the page, so nothing is loaded and the page offers no way on. <kbd>CLR</kbd> goes back one step at a time, to the end of the database cycle and then to the first screen, both without the cursor.
</Field>

<Field id="page" title="Page identification">
	`SET 0` is the only page identification that the status line shows while this page is on. The mode annunciation and the right page identification are blank.
</Field>
