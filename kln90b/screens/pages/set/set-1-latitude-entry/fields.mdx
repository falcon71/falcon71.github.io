<Field id="title" title="Page title">
	`INIT POSN` heads the page on which you tell the unit where the aircraft is.
</Field>

<Field id="wpt" title="Waypoint of the position">
	The identifier of a waypoint that the position can be taken from. The field is blank until you enter one, and entering one fills in the latitude and longitude below.
</Field>

<Field id="lat" title="Latitude being entered">
	The latitude as an entry that is not accepted yet: the unit shows it in inverse video, and the cell under the cursor flashes. The first step of the left inner knob opens the entry and replaces the old value with underscores, except for the first cell, which shows its first value, `N`. Cells that are still underscores count as 0 when <kbd>ENT</kbd> accepts the entry ([Entries that take effect with ENT](/kln90b/unit/controls-and-display/#entries-that-take-effect-with-ent) describes the entry).
</Field>

<Field id="lon" title="Longitude">
	The longitude, entered the same way as the latitude. <kbd>ENT</kbd> on the latitude moves the cursor to it.
</Field>

<Field id="speed" title="Groundspeed and heading">
	The groundspeed in kt, 0 to 999, and the magnetic heading in degrees, 0° to 359°. Each is an entry that takes effect with <kbd>ENT</kbd>, like the latitude. They have no effect on the search for satellites.
</Field>

<Field id="confirm" title="Confirm the position">
	`CONFIRM?` is a button: <kbd>ENT</kbd> with the cursor on it takes over the values of the page as the position of the aircraft.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> takes the place of the page identification of the left side while that side's cursor is on.
</Field>
