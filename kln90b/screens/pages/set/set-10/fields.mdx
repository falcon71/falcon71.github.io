<Field id="gps" title="GPS acquisition mode">
	`GPS:` and the mode the receiver acquires in: `REAL` or `FAST`. The left inner knob changes the mode with the cursor on, without <kbd>ENT</kbd>. The unit stores the mode at once. `FAST` chosen while the unit is not NAV ready restarts the search at once; `FAST` chosen while it is NAV ready, and `REAL` at any time, take effect at the next power-on. [Real and fast acquisition](/kln90b/operation/gps-receiver/#real-and-fast-acquisition) explains the two modes.
</Field>

<Field id="failures" title="Button to the failure pages">
	The button `FAILURES?` opens FLR 1, the first of the three FLR pages. [The FLR pages](/kln90b/pages/flr/#the-flr-pages-failing-and-repairing-parts-of-the-unit) explain how they open.
</Field>

<Field id="page" title="Page identification">
	The page identification of the left page, `SET10`. The unit writes it without a space because the room on the status line is short.
</Field>
