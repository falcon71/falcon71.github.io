<Field id="title" title="Page title">
	`FLIGHT TIMER OPERATION` heads the page that sets when the flight timer runs.
</Field>

<Field id="run" title="When the flight timer runs">
	{/* kln90b#522: describes the current behavior (30 kt or more); the fix makes it above 30 kt */}
	`RUN WHEN` and the condition. `POWER IS ON` runs the timer for as long as the unit is on, `GS > 30kt` while the groundspeed is 30 kt or more. The left inner knob switches between the two with the cursor on, and the change takes effect at once, without <kbd>ENT</kbd>.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> replaces the page identification while the left cursor is on. Pressing the left <kbd>CRSR</kbd> button turns the cursor off again, and the page name returns.
</Field>
