<Field id="title" title="Page title">
	The name of the setting: the criteria that an airport must meet to appear in the [nearest list](/kln90b/operation/nearest/) of airports.
</Field>

<Field id="length" title="Minimum runway length">
	The shortest runway, in ft, that an airport needs to appear in the nearest list of airports. The values run from 1,000 ft to 5,000 ft in steps of 100 ft. With the cursor on, the left inner knob changes the value at once, and the field needs no <kbd>ENT</kbd>.
</Field>

<Field id="surface" title="Runway surface">
	`HRD SFT` accepts airports with a hard or a soft runway, `HRD` only airports with a hard runway. With the cursor on, the left inner knob changes the choice at once.
</Field>

<Field id="page" title="Page identification">
	The page identification of the left page, `SET 3`.
</Field>
