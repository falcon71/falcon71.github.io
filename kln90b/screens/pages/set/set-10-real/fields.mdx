<Field id="gps" title="GPS acquisition mode">
	`GPS:` and the mode the receiver acquires in, `REAL` or `FAST`. The cursor starts here when you turn it on, and the left inner knob changes the mode without <kbd>ENT</kbd>. The unit stores the mode at once. `FAST` chosen while the unit is not NAV ready restarts the search at once; `FAST` chosen while it is NAV ready, and `REAL` at any time, take effect at the next power-on. [Real and fast acquisition](/kln90b/operation/gps-receiver/#real-and-fast-acquisition) explains the setting.
</Field>

<Field id="failures" title="Button to the failure pages">
	The button `FAILURES?` opens FLR 1, the first of the three FLR pages.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> replaces the page identification while the left cursor is on. Pressing the left <kbd>CRSR</kbd> button turns the cursor off again, and the page name returns.
</Field>
