<Field id="title" title="Page title">
	`BARO SET UNITS` heads the page that chooses the unit of the altimeter baro setting.
</Field>

<Field id="unit" title="Unit of the baro setting">
	The unit in which the unit shows and takes the baro setting: inches, shown as the inch mark above `INCHES`, or millibars, shown as `MB` above `MILLIBARS`. With the cursor on, the left inner knob changes the unit at once, without <kbd>ENT</kbd>.
</Field>

<Field id="page" title="Page identification">
	The page identification of the left page, `SET 7`.
</Field>
