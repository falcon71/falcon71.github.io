<Field id="title" title="Page title">
	The name of the setting: the criteria that an airport must meet to appear in the nearest airport list.
</Field>

<Field id="length" title="Minimum runway length">
	The shortest runway, in ft, that an airport needs to appear in the nearest airport list. With the cursor on, the left inner knob steps through the values from 1000 to 5000 in steps of 100, and the change takes effect at once. The field needs no <kbd>ENT</kbd>.
</Field>

<Field id="surface" title="Runway surface">
	`HRD SFT` accepts airports with hard or soft runways, `HRD` only airports with a hard runway. The left outer knob moves the cursor here from the minimum length, and the left inner knob changes the choice at once.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> replaces the page identification while the left cursor is on. Pressing the left <kbd>CRSR</kbd> button turns the cursor off again, and the page name returns.
</Field>
