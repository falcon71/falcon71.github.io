<Field id="title" title="Page title">
	`U P D A T E`, the title of the page, in letters spread apart. It is a full-screen page, which takes both halves of the screen.
</Field>

<Field id="region" title="Database region">
	`INTERNATIONAL` names the area that the database covers. The text is fixed.
</Field>

<Field id="status" title="Database status">
	`DATA BASE EXPIRES` says that the database cycle has not ended yet. When the clock of the unit is past the end of the cycle, `DATA BASE EXPIRED` takes its place.
</Field>

<Field id="date" title="End of the database cycle">
	The last day of the database cycle, day, month and year, with the same value as on the Database page of the power-on sequence.
</Field>

<Field id="update" title="Update question">
	The update question, `U P D A T E ?`, is a button. <kbd>ENT</kbd> with the cursor on it shows `L O A D E R` `N O T   R E A D Y`. <kbd>CLR</kbd> goes back one step.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> takes the place of the page identification of the left side while that side's cursor is on.
</Field>

<Field id="prompt" title="Enter prompt">
	The enter prompt <Term t="ENT">`ENT`</Term> flashes while <kbd>ENT</kbd> accepts what the cursor is on.
</Field>
