<Field id="value" title="Turn anticipation setting">
	`DISABLE` turns turn anticipation off, `ENABLE` turns it on. With the cursor on, the left inner knob switches between the two, and the change takes effect at once, without <kbd>ENT</kbd>.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> takes the place of the page identification of the left side while that side's cursor is on.
</Field>
