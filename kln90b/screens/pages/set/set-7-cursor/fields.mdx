<Field id="title" title="Page title">
	`BARO SET UNITS` heads the page that chooses the unit of the altimeter baro setting.
</Field>

<Field id="unit" title="Unit of the baro setting">
	The unit in which the unit shows and takes the baro setting: millibars, shown as `MB` above `MILLIBARS`, or inches, shown as the inch mark above `INCHES`. The left inner knob switches between them with the cursor on, and the change takes effect at once, without <kbd>ENT</kbd>.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> replaces the page identification while the left cursor is on. Pressing the left <kbd>CRSR</kbd> button turns the cursor off again, and the page name returns.
</Field>
