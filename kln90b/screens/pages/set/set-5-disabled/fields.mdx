<Field id="title" title="Page title">
	`HT ABOVE APT ALERT` heads the page of the height above airport alert.
</Field>

<Field id="off" title="Height above airport alert">
	`OFF` is the only state the page shows in an installation without altitude alerting. You cannot change it, because the cursor cannot go to the page.
</Field>

<Field id="disabled" title="Feature disabled">
	`FEATURE DISABLED` says that the installation of the unit has no altitude alerting, and so no height above airport alert.
</Field>

<Field id="page" title="Page identification">
	The page identification of the left page, `SET 5`.
</Field>
