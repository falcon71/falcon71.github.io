<Field id="title" title="Mode is active">
	`ACTIVE MODE` shows that the unit navigates in [leg mode](/kln90b/operation/modes-of-operation/#leg-mode), the course mode of this page. In Approach Arm-Leg mode and Approach Active-Leg mode the page shows it as well.
</Field>

<Field id="leg" title="Leg mode">
	`LEG` names the course mode of this page. MOD 1 is the page of [leg mode](/kln90b/operation/modes-of-operation/#leg-mode), MOD 2 the page of [OBS mode](/kln90b/operation/modes-of-operation/#obs-mode).
</Field>

<Field id="scale" title="CDI scale factor">
	The [CDI scale factor](/kln90b/operation/modes-of-operation/#the-cdi-scale): the cross-track distance at which the D-bar and the external indicator reach full scale, ±5.00, ±1.00 or ±0.30 NM. With the cursor on it, the left inner knob selects another one, which takes effect at once. Which you can select depends on the mode.
</Field>

<Field id="page" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> replaces the page identification while the left cursor is on.
</Field>
