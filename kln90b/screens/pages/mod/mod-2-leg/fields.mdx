<Field id="title" title="Prompt to change the mode">
	`PRESS ENT` `TO ACTIVATE`: the unit is in [leg mode](/kln90b/operation/modes-of-operation/#leg-mode). <kbd>ENT</kbd> changes it to [OBS mode](/kln90b/operation/modes-of-operation/#obs-mode), with the cursor on or off, and the enter prompt `ENT` shows in the status line while this page is shown. This prompt appears only without a GPS CRS switch; with one, the page shows `PRESS GPS` `CRS FOR` and <kbd>ENT</kbd> does nothing. Without an active waypoint the unit stays in leg mode and shows `NO ACTV WPT`.
</Field>

<Field id="course" title="Selected course">
	In leg mode the course shows dashes, because only OBS mode has a selected course. The colon after `OBS` does not depend on the mode: it shows where you set the selected course on the unit, as in `OBS:---°`, and is missing where the unit reads it from the external indicator, as in `OBS ---°`. In an aircraft whose unit reads the indicator, the colon appears while the KLN 90B is not the displayed navigation source. See [The selected course](/kln90b/operation/modes-of-operation/#the-selected-course).
</Field>

<Field id="scale" title="CDI scale factor">
	The [CDI scale factor](/kln90b/operation/modes-of-operation/#the-cdi-scale-factor): the cross-track error at which the D-bar and the external indicator reach full scale. With the cursor on it, the left inner knob selects another one.
</Field>

<Field id="page" title="Page identification">
	The page identification of the left page, `MOD 2`.
</Field>
