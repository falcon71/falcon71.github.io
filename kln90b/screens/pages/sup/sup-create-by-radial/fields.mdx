<Field id="ident" title="Identifier of the user waypoint">
	The identifier of the [user waypoint](/kln90b/operation/user-waypoints/), as you entered it before the unit created the waypoint.
</Field>

<Field id="ref" title="Reference waypoint">
	The waypoint that you entered as the reference, which can be a waypoint of any type. The unit created the user waypoint on the radial and at the distance that follow, and the page keeps showing the reference you chose while it stays shown. The reference is not stored with the waypoint: when you come back to the page, the unit shows radial and distance from the nearest VOR.
</Field>

<Field id="rad" title="Radial from the reference waypoint">
	The magnetic course from the reference waypoint to the user waypoint, in degrees and tenths, magnetic with the variation of the reference waypoint. Changing it moves the user waypoint onto the new radial at the same distance.
</Field>

<Field id="dis" title="Distance from the reference waypoint">
	The distance from the reference waypoint to the user waypoint in NM, to a tenth. Changing it moves the user waypoint along the same radial.
</Field>

<Field id="lat" title="Latitude of the user waypoint">
	The latitude that the unit computed from the reference waypoint, the radial and the distance. It can be changed like the latitude of any user waypoint.
</Field>

<Field id="lon" title="Longitude of the user waypoint">
	The longitude that the unit computed from the reference waypoint, the radial and the distance. It can be changed like the longitude of any user waypoint.
</Field>

<Field id="page" title="Page identification">
	The page identification on the right side.
</Field>
