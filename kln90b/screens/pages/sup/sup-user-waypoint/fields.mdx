<Field id="ident" title="Identifier of the user waypoint">
	The identifier of the [user waypoint](/kln90b/operation/user-waypoints/). The arrow in front of it means that the waypoint is the [active waypoint](/kln90b/operation/modes-of-operation/#the-active-waypoint). The identifier cannot be changed after the waypoint is created.
</Field>

<Field id="ref" title="Reference waypoint">
	The waypoint that `RAD` and `DIS` are measured from. For a waypoint that was not made from a reference, the unit fills it in with the VOR nearest to the waypoint after a search, and the field shows underscores until it has found one ([The reference waypoint](/kln90b/pages/int/#the-reference-waypoint)). You can enter any waypoint instead: the unit shows it on its waypoint page for approval, and the page then shows radial and distance from it. A new reference moves nothing. <kbd>CLR</kbd> on `REF` empties the reference, which then shows underscores, but leaves `RAD` and `DIS` as they were, and a radial or a distance you enter afterwards then moves nothing. {/* kln90b#490: describes the current behavior; the fix keeps RAD and DIS in step with the position */}
</Field>

<Field id="rad" title="Radial from the reference waypoint">
	The magnetic course from the reference waypoint to the user waypoint, in degrees and tenths, magnetic with the variation of the reference. A new radial moves the user waypoint along the new radial at the same distance from the reference waypoint. As long as there is no reference waypoint, a radial you enter is shown but moves nothing. After you change the latitude or the longitude, the radial and the distance keep their old values until the page is shown again; a reference waypoint, a center waypoint or a DME arc waypoint that the unit made keeps the radial and the distance it was made with even then. {/* kln90b#490: describes the current behavior; the fix keeps RAD and DIS in step with the position */}
</Field>

<Field id="dis" title="Distance from the reference waypoint">
	The distance from the reference waypoint to the user waypoint in NM, to a tenth. A new distance moves the user waypoint along the same radial. As long as there is no reference waypoint, a distance you enter is shown but moves nothing. After you change the latitude or the longitude, the radial and the distance keep their old values until the page is shown again; a reference waypoint, a center waypoint or a DME arc waypoint that the unit made keeps the radial and the distance it was made with even then. {/* kln90b#490: describes the current behavior; the fix keeps RAD and DIS in step with the position */}
</Field>

<Field id="lat" title="Latitude of the user waypoint">
	The latitude of the user waypoint, in degrees and minutes to hundredths. With the cursor on, a new latitude moves the waypoint when you press <kbd>ENT</kbd>, and the stored waypoint changes at once.
</Field>

<Field id="lon" title="Longitude of the user waypoint">
	The longitude of the user waypoint, in degrees and minutes to hundredths. With the cursor on, a new longitude moves the waypoint when you press <kbd>ENT</kbd>, and the stored waypoint changes at once.
</Field>

<Field id="page" title="Page identification">
	The page identification on the right side.
</Field>
