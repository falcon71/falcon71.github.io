<Field id="text" title="VFR-only notice">
	`FOR VFR USE ONLY` tells you that the unit is installed for VFR flight only.
</Field>

<Field id="acknowledge" title="Acknowledgment">
	Pressing <kbd>ENT</kbd> with the cursor on `ACKNOWLEDGE?` leaves the page. The unit then shows the next power-on page.
</Field>

<Field id="mode" title="Mode annunciation">
	The mode annunciation, which shows the mode of the unit. <Term t="ENR-LEG">`ENR-LEG`</Term> is Enroute-Leg mode, en route navigation along a leg.
</Field>

<Field id="prompt" title="Message and enter prompt">
	The three cells after the mode annunciation. A flashing <Term t="ENT">`ENT`</Term> means that <kbd>ENT</kbd> accepts what the cursor is on. <Term t="MSG">`MSG`</Term> flashes in the same cells while the unit holds a message you have not read, and is steady once you have read every message it holds ([The message prompt](/kln90b/operation/messages/#the-message-prompt)). They are blank when neither applies.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> shows that the right cursor is on. This page shows no page identifications. Pressing the right <kbd>CRSR</kbd> button turns the cursor off.
</Field>
