<Field id="warning" title="Warning">
	`WARNING` marks the page as a warning. The page has no `ACKNOWLEDGE?` and no cursor field.
</Field>

<Field id="mode" title="Mode annunciation">
	The mode annunciation, which shows the mode of the unit. <Term t="ENR:">`ENR:`</Term> is Enroute-OBS mode, with the selected course that follows it. The page leaves by itself when the switch selects leg mode.
</Field>

<Field id="text" title="Instruction">
	`SYSTEM IS IN OBS MODE` `PRESS GPS CRS BUTTON` `TO CHANGE TO LEG MODE`: the unit is in OBS mode, and the GPS CRS switch of the aircraft changes it to leg mode.
</Field>
