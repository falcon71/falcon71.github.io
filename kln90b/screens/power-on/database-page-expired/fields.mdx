<Field id="region" title="Database region">
	`INTERNATIONAL` names the area that the database covers, here the whole world, because the unit uses the worldwide navigation data of the simulator. The text is fixed.
</Field>

<Field id="status" title="Database status">
	`DATA BASE EXPIRED` says that the clock of the unit has passed the end of the database cycle. While the database is current, `DATA BASE EXPIRES` takes its place.
</Field>

<Field id="date" title="End of the database cycle">
	The last day of the database cycle, day, month and year.
</Field>

<Field id="warning" title="Warning about the data">
	`ALL DATA MUST BE` `CONFIRMED BEFORE USE` appears only with an expired database. Check the data against a current source before you rely on it.
</Field>

<Field id="acknowledge" title="Acknowledgment">
	Pressing <kbd>ENT</kbd> with the cursor on `ACKNOWLEDGE?` ends the power-on pages. The unit then shows the [first pages](/kln90b/unit/power-on/#the-first-pages).
</Field>

<Field id="mode" title="Mode annunciation">
	The mode annunciation, which shows the mode of the unit. <Term t="ENR-LEG">`ENR-LEG`</Term> is Enroute-Leg mode, en route navigation along a leg.
</Field>

<Field id="prompt" title="Message and enter prompt">
	The three cells after the mode annunciation. A flashing <Term t="ENT">`ENT`</Term> means that <kbd>ENT</kbd> accepts what the cursor is on. <Term t="MSG">`MSG`</Term> flashes in the same cells while the unit holds a message you have not read, and is steady once you have read every message it holds ([The message prompt](/kln90b/operation/messages/#the-message-prompt)). They are blank when neither applies.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> shows that the right cursor is on. This page shows no page identifications. Pressing the right <kbd>CRSR</kbd> button turns the cursor off.
</Field>
