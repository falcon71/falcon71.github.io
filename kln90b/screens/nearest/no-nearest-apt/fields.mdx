<Field id="mode" title="Mode annunciation">
	The mode annunciation; `ENR-LEG` is Enroute-Leg mode. It stays in the status line while the MSG page is shown.
</Field>

<Field id="msg" title="Message prompt">
	<Term t="MSG" /> is steady: you have read every message the unit holds; it flashes while one is unread ([The message prompt](/kln90b/operation/messages/#the-message-prompt)). It stands in the status line while the MSG page is shown, also when the unit holds no message, and the page above it is blank. Pressing <kbd>MSG</kbd> again closes the page.
</Field>
