<Field id="hardware" title="Receiver hardware error 0008">
	The GPS receiver has lost its memory: its almanac data and its ephemeris data. The code `0008` goes once the receiver tracks its first satellite of this power-on. See [The receiver and the antenna](/kln90b/operation/failures/#the-receiver-and-the-antenna).
</Field>
<Field id="battery" title="Battery low">
	The internal battery that keeps the user data while the unit is off is nearly empty, or has failed. The message stays while the condition lasts; a service on FLR 1 puts in a new battery. See [The battery](/kln90b/operation/failures/#the-battery).
</Field>
<Field id="lost" title="User data lost">
	The unit has lost the data it keeps while it is off: user waypoints, flight plans, remarks and settings. The MSG page shows it once, after the power-on at which the loss happened. See [The battery](/kln90b/operation/failures/#the-battery).
</Field>
<Field id="mode" title="Mode annunciation">
	The mode annunciation; `ENR-LEG` is Enroute-Leg mode. It stays in the status line while the MSG page is shown.
</Field>
<Field id="msg" title="Message prompt">
	<Term t="MSG" /> in inverse video: the unit holds messages. It is steady once you have read them all and flashes while one is unread. Pressing <kbd>MSG</kbd> shows the next page of messages or closes the MSG page.
</Field>
