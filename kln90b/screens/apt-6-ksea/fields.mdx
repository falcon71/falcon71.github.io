<Field id="ident" title="Airport identifier">
	The identifier of the airport. It is the same on every APT page and is changed in the same way as on APT 1.
</Field>

<Field id="fuel" title="Fuel">
	The row for the fuel available at the airport. The simulator has no fuel data, so the unit shows `NO FUEL` for every airport; it does not mean that the airport has no fuel.
</Field>

<Field id="oxygen" title="Oxygen">
	The row for the oxygen available at the airport. The simulator has no oxygen data, so the unit shows `NO OXYGEN` for every airport.
</Field>

<Field id="fee" title="Fees">
	The row for fee information about the airport. The simulator has no such data, so the unit shows `NO FEE INFO` for every airport.
</Field>

<Field id="page" title="Page name">
	The name of the page on the right side.
</Field>
