<Field id="message" title="Waypoints twice in FPL 0">
	The procedure you loaded has a waypoint that FPL 0 holds already as an en route waypoint, so FPL 0 now holds it twice. The unit keeps both. Delete the copies you do not need. See [`REDUNDANT WPTS IN FPL`](/kln90b/operation/departures-arrivals/#redundant-wpts-in-fpl).
</Field>

<Field id="mode" title="Mode annunciation">
	The mode annunciation, which shows the mode of the unit. <Term t="ENR-LEG">`ENR-LEG`</Term> is Enroute-Leg mode.
</Field>

<Field id="msg" title="Message prompt">
	<Term t="MSG">`MSG`</Term> without inverse video: the MSG page is shown, and the unit holds no message any more. <kbd>MSG</kbd> closes the page ([The message prompt](/kln90b/operation/messages/#the-message-prompt)).
</Field>
