<Field id="message" title="Holding pattern or procedure turn ahead">
	The active waypoint is the fix of a holding pattern or a procedure turn of a procedure, it is 4 NM away or less, and the unit is not in OBS mode. The unit does not fly the pattern; to fly it, select OBS mode. See [`IF REQUIRED SELECT OBS`](/kln90b/operation/departures-arrivals/#if-required-select-obs).
</Field>

<Field id="mode" title="Mode annunciation">
	The mode annunciation, which shows the mode of the unit. <Term t="ENR-LEG">`ENR-LEG`</Term> is Enroute-Leg mode.
</Field>

<Field id="msg" title="Message prompt">
	<Term t="MSG">`MSG`</Term> steady in inverse video: you have read every message the unit holds; it flashes while one is unread. <kbd>MSG</kbd> shows the next one or closes the page after the last ([The message prompt](/kln90b/operation/messages/#the-message-prompt)).
</Field>
