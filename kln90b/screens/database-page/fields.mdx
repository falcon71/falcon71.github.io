<Field id="region" title="Database region">
	`INTERNATIONAL` names the area that the database covers, here the whole world, because the unit uses the worldwide navigation data of the simulator. The text is fixed.
</Field>

<Field id="status" title="Database status">
	`DATA BASE EXPIRES` says that the database is current: the clock of the unit has not passed the end of its cycle. When it has, `DATA BASE EXPIRED` takes its place.
</Field>

<Field id="date" title="End of the database cycle">
	The last day of the database cycle, day, month and year. The unit compares it with its own date and time.
</Field>

<Field id="acknowledge" title="Acknowledgment">
	Pressing <kbd>ENT</kbd> with the cursor on `ACKNOWLEDGE?` ends the power-on pages. The unit then shows its normal pages.
</Field>

<Field id="mode" title="Mode annunciation">
	The mode annunciation, which shows the navigation mode. <Term t="ENR-LEG">`ENR-LEG`</Term> is Enroute-Leg mode, en route navigation along a leg.
</Field>

<Field id="prompt" title="Message and enter prompt">
	The three cells after the mode annunciation. <Term t="MSG">`MSG`</Term> in inverse video means that the unit holds a message, and a flashing <Term t="ENT">`ENT`</Term> means that <kbd>ENT</kbd> accepts what the cursor is on. They are blank when neither applies.
</Field>

<Field id="crsr" title="CRSR annunciation">
	<Term t="CRSR">`CRSR`</Term> shows that the right cursor is on. This page shows no page identifications. Pressing the right <kbd>CRSR</kbd> button turns the cursor off.
</Field>
