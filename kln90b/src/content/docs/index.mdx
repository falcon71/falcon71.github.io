The KLN 90B is a panel-mounted GPS navigator of the 1990s, built for instrument flight en route and on
non-precision approaches. It has no touchscreen and no colors: you read pages of green text, select them with a pair of
concentric knobs on each side and enter waypoints letter by letter. The simulation for Microsoft Flight Simulator
follows the real unit closely, quirks included.

## KLN 90B Simulator Manual

This manual explains how to operate the KLN 90B, from the first power-on to a non-precision approach. If the unit is
new to you, start with [Getting started](/kln90b/getting-started/).
