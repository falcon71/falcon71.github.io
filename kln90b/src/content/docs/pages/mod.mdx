The MOD pages of the KLN 90B select the course mode: MOD 1 is the page of [leg mode](/kln90b/operation/modes-of-operation/#leg-mode), MOD 2 the page of [OBS mode](/kln90b/operation/modes-of-operation/#obs-mode). Both set the [CDI scale factor](/kln90b/operation/modes-of-operation/#the-cdi-scale-factor), and MOD 2 shows the [selected course](/kln90b/operation/modes-of-operation/#the-selected-course). They are left pages.

## The MOD pages: one page for each course mode

<Callout kind="availability">
Whether the aircraft has a GPS CRS switch depends on how the unit is installed. Most installations have one; without it, <kbd>ENT</kbd> on the MOD pages changes the course mode.
</Callout>

The page of the course mode the unit navigates in shows `ACTIVE MODE` at the top. With a GPS CRS switch, the page of the other mode shows `PRESS GPS` `CRS FOR` instead, with no enter prompt, and the mode name below completes the sentence: `PRESS GPS CRS FOR OBS` on MOD 2, `PRESS GPS CRS FOR LEG` on MOD 1. The switch changes the course mode, and <kbd>ENT</kbd> does nothing on the MOD pages ([Selecting leg or OBS mode](/kln90b/operation/modes-of-operation/#selecting-leg-or-obs-mode)). MOD 1 counts Approach Arm-Leg mode and Approach Active-Leg mode as leg mode, and MOD 2 counts Approach Arm-OBS mode as OBS mode.

<KlnScreen screen="pages/mod/mod-2-switch" />

The CDI scale factor at the bottom is one setting, shown on both pages: a change on one shows on the other.

### Without a GPS CRS switch

The page of the other mode shows `PRESS ENT` `TO ACTIVATE`, the enter prompt `ENT` flashes in the status line while it is shown, and <kbd>ENT</kbd> changes to its mode, with the cursor on or off ([Without a GPS CRS switch](/kln90b/operation/modes-of-operation/#without-a-gps-crs-switch)). The screens of MOD 1 and MOD 2 below show this prompt.

## MOD 1: leg mode

MOD 1 shows whether leg mode is active and holds the CDI scale factor. You use it to see whether leg mode is active and to change the CDI scale factor; without a GPS CRS switch, you also use it to change back to leg mode.

<KlnScreen screen="pages/mod/mod-1-leg" />

The cursor goes only to the CDI scale factor.

<KlnScreen screen="pages/mod/mod-1-cursor" />

In OBS mode the page tells you to set the GPS CRS switch to leg mode, `PRESS GPS CRS FOR LEG`; without a switch, it asks you to press <kbd>ENT</kbd>.

<KlnScreen screen="pages/mod/mod-1-switch" />

<KlnScreen screen="pages/mod/mod-1-obs" />

[Selecting leg or OBS mode](/kln90b/operation/modes-of-operation/#selecting-leg-or-obs-mode), [The CDI scale factor](/kln90b/operation/modes-of-operation/#the-cdi-scale-factor) and [The CDI scale factor along the approach](/kln90b/operation/approaches/#the-cdi-scale-factor-along-the-approach) describe the tasks that use MOD 1.

## MOD 2: OBS mode

MOD 2 shows whether OBS mode is active, the selected course and the CDI scale factor. You use it to see whether OBS mode is active and to set the selected course; without a GPS CRS switch, you also use it to change to OBS mode.

<KlnScreen screen="pages/mod/mod-2-obs" />

In leg mode the page shows `PRESS GPS CRS FOR OBS` with a GPS CRS switch and `PRESS ENT` `TO ACTIVATE` without one.

<KlnScreen screen="pages/mod/mod-2-leg" />

How the unit is connected to the external indicator selects the variant of the course line: with a colon where you set the course on the unit, in leg mode too, and without one where the unit takes the course from the indicator. In an aircraft whose unit reads the indicator, the colon appears while the KLN 90B is not the displayed navigation source.

<KlnScreen screen="pages/mod/mod-2-obs-indicator" />

With the colon, in OBS mode, the cursor starts on the course and moves on to the CDI scale factor; otherwise it goes only to the CDI scale factor.

<KlnScreen screen="pages/mod/mod-2-obs-cursor" />

[Selecting leg or OBS mode](/kln90b/operation/modes-of-operation/#selecting-leg-or-obs-mode), [The selected course](/kln90b/operation/modes-of-operation/#the-selected-course) and [The CDI scale factor](/kln90b/operation/modes-of-operation/#the-cdi-scale-factor) describe the tasks that use MOD 2.
